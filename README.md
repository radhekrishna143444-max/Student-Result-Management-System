# Student Progress Card System

A Java-based application that allows students' marks to be entered and automatically calculates total marks, average percentage, and grade.

## Features
- Enter Student Details
- Input Subject Marks
- Calculate Total Marks
- Calculate Average Percentage
- Generate Grade
- Display Student Result

## Technologies Used
- Java
- OOP Concepts
- Eclipse IDE

## Concepts Practiced
- Classes and Objects
- Methods
- Conditional Statements
- Loops
- User Input Handling

## Purpose
This project was developed to practice Java programming and build a real-world student result management system.
